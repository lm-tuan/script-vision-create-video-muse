## 処理ルール

### ルール1：書式記号を完全に削除する

- Markdownの記号（`###`、`---`、`**`、`*`、`>`、`-`、`#`など）をすべて削除する。
- 箇条書きや見出しは、読み上げ時に自然に聞こえる完全な文章へ変換する。
  - 例: `### 第1のルール` → `最初のルールについてお話しします。`
  - 例: `- タンパク質を摂る` → `まず、タンパク質をしっかり摂ることが大切です。`

### ルール2：英字略語をカタカナ読みに変換する

ラテン文字のアルファベット略語は、AIが正しく読めるようにカタカナで各文字を「・（中黒）」で区切って表記する。

| 変換前 | 変換後 |
|--------|--------|
| TDEE | ティー・ディー・イー・イー |
| AI | エー・アイ |
| SNS | エス・エヌ・エス |
| ISSN | アイ・エス・エス・エヌ |
| ChatGPT | チャット・ジー・ピー・ティー |
| DNA | ディー・エヌ・エー |
| BMI | ビー・エム・アイ |
| URL | ユー・アール・エル |

- 一般的に日本語読みが定着しているもの（例: `PC → ピーシー`, `TV → テレビ`）はそのままカタカナで表記してよい。

### ルール3：数字・単位を漢字／カタカナ表記に変換する

TTS が正確なアクセント・区切りで読み上げられるよう、数値と単位を文字表記へ変換する。

**小数点を含む数値（必ずこの形式で）：**
- `1.6g` → `一点六グラム`
- `3.4g` → `三点四グラム`
- `12.5%` → `十二点五パーセント`

**整数・大きな数（漢数字へ）：**
- `500kcal` → `五百キロカロリー`
- `10個` → `十個`
- `10セット` → `十セット`
- `1回` → `一回`
- `2024年` → `二千二十四年`
- `100%` → `百パーセント`

**単位の読み方：**
- `km/h` → `キロメートル毎時`
- `mg` → `ミリグラム`
- `μg` → `マイクログラム`
- `CO₂` → `二酸化炭素`（または `シーオーツー`）

### ルール4：句読点・読み上げリズムを最適化する

- 句読点（`。`、`、`）を適切な位置に配置し、TTSが自然に間を取れるようにする。
- 一文が長すぎる場合は、意味が通じる最小単位で区切る（一文は40文字を目安）。
- 1段落は2〜3文を目安とし、段落間に空行を入れる。
- 修辞的な疑問文の後には必ず空行を入れて、TTSが間を取れるようにする。

### ルール5：文体・内容を保持する

- 原文の語気、情報、数値、固有名詞、主要な論点を一切省略・変更しない。
- 原文に存在しない情報を追加でつくらない。
